# cp5-frontend-imgs

Repositório com as imagens das resoluções dos sites de treinamento de CSS.

## Conteúdo

- `css-garden/`: capturas de tela das resoluções dos níveis do CSS Garden
- `flexbox-froggy/`: capturas de tela das resoluções dos níveis do Flexbox Froggy

Cada imagem mostra o código da solução e o resultado do nível correspondente.
